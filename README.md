# Tokyo Суши

Мобильное приложение для заказа еды с отдельной веб-панелью управления. Клиентская часть написана на **Flutter (Dart)**, сервер и API — на **Python (FastAPI)**. Каталог, дополнения к блюдам и заказы хранятся в **SQLite**.

Проект находится в разработке. Сейчас он рассчитан прежде всего на локальное тестирование и доработку, а не на работу с реальными платежами.

## Возможности

### Мобильное приложение

- Каталог блюд с категориями, фотографиями, описаниями и ценами в тенге.
- Слайдер хитов с автоматическим переключением и просмотром в формате сторис.
- Просмотр блюда с перелистыванием, выбором дополнений и количества.
- Корзина с расчётом стоимости и оформление заказа через API.
- Избранное и профиль пользователя.
- Вход по одноразовому коду через Telegram-бота.
- Тёмный графитовый интерфейс с матовыми панелями и плавной навигацией.

### Панель администратора

- Добавление и управление категориями.
- Создание и редактирование блюд, цен и доступности.
- Загрузка и обрезка фотографий, предварительный просмотр карточек.
- Настройка хитов для главного экрана.
- Группы дополнений: например, соус или дополнительная порция ингредиента, с собственными ценами и ограничениями выбора.
- Просмотр заказов и изменение их статуса.

Админка и мобильное приложение работают с одной базой через HTTP API. Данные каталога не зашиты в приложение: новые позиции добавляются через панель управления.

| Часть | Технологии | Для чего используется |

## Локальный запуск

Нужны установленный [Flutter SDK](https://docs.flutter.dev/get-started/install), Python и Android SDK для запуска на телефоне. Команды ниже приведены для PowerShell в Windows.

### 1. Сервер и админ-панель

```powershell
cd food_delivery_admin
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Настройте переменные окружения **до** запуска сервера:

```powershell
$env:FOOD_ADMIN_USER = "admin"
$env:FOOD_ADMIN_PASSWORD = Read-Host "Пароль администратора"
$env:AUTH_SECRET = Read-Host "Секрет авторизации (длинная случайная строка)"
```

Запуск API с Telegram-авторизацией:

```powershell
.\.venv\Scripts\python.exe -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Админка доступна по адресу `http://127.0.0.1:8000`. Проверка API: `http://127.0.0.1:8000/api/health`.

### 2. Telegram-бот

Создайте бота через [@BotFather](https://t.me/BotFather). В **другом** окне PowerShell:

```powershell
cd food_delivery_admin
$env:TELEGRAM_BOT_TOKEN = Read-Host "Токен Telegram-бота"
$env:AUTH_SECRET = Read-Host "Тот же секрет авторизации"
.\.venv\Scripts\python.exe telegram_bot.py
```

Бот использует Telegram Bot API. Для получения кода он должен быть запущен одновременно с сервером. В текущей конфигурации тестовый бот проекта — [@tokyodeltest_bot](https://t.me/tokyodeltest_bot).

### 3. Flutter

В третьем терминале:

```powershell
cd food_delivery
flutter pub get
flutter devices
flutter run --dart-define=API_BASE_URL=http://АДРЕС_КОМПЬЮТЕРА:8000
```

На физическом Android-устройстве укажите локальный IP компьютера, доступный телефону по Wi-Fi. Адрес `127.0.0.1` на телефоне относится к самому телефону, а не к компьютеру.

Для удалённого тестирования можно использовать HTTPS-туннель, например ngrok, и передать его адрес через `API_BASE_URL`. Не публикуйте тестовую админку с простым паролем.

## Как устроен заказ

1. Администратор создаёт категорию и блюдо, при необходимости добавляет варианты и цены дополнений.
2. Приложение загружает актуальный каталог через API.
3. Пользователь выбирает блюдо, дополнения и количество, добавляет их в корзину.
4. При оформлении сервер повторно рассчитывает сумму по данным базы.
5. Заказ появляется в админ-панели, где можно менять его статус.
